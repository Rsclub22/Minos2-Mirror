Building under MacOS X
======================

This is based on Xcode on MacOS Sonoma 


1) Install Xcode from developer.apple.com.  You will need to register for a developer account using your apple ID.  
2) Install the HomeBrew package manager from brew.sh
	/usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
3) Install dependencies:
	brew install git
    
4) Install Qt
    Download the QT installer - go to https://www.qt.io/download-qt-installer
    Run the installer. You will need to set up a Qt account.
    
    Install at least Qt 6.6.0. Under "Additional libraries" you need at least 
        Qt Charts, Qt Location, Qt positioning and Qt Serial Port
 
5) Download Minos Source Code
	NB other scripts refer to $HOME/Minos2, so you're stuck with it. 

	cd ~
	git clone git://git.code.sf.net/p/minos/minos Minos2
	cd Minos2
    git checkout Mqt_Release_2.7.x.x

6) Install other required components

	./mactools.sh


7) Get and build the latest Hamlib

Look at https://github.com/Hamlib/Hamlib for all the up to date hamlib information,
including their build instructions, from which the following is derived.

This means that you have to download and build it yourself; here is one recipe:

cd ~

to be sure you are in your home directory,
Then

git clone https://github.com/Hamlib/Hamlib.git

cd Hamlib

If 4.6 has been released

# get the hamlib 4.6.0 release branch

git checkout Hamlib-4.6.0


Otherwise, 

# get the main development branch

git checkout master

# and run the build

./bootstrap
./configure
make
sudo make install

8) You should now be able to go ahead with the build.

	export PATH="~/qt/6.6.0/bin:$PATH"
	cd ~/mqt/Installer
	./macInstall.sh

9) And then run it with
	open -a ~/minos-runtime/MqtLogger.app

To update and buid again, repeat from after "git clone"
