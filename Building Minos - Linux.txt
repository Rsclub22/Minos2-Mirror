Building under Linux
====================

Currently, these instructions work under Ubuntu, and also on the Raspberry Pi
where the default oS is similar enough to Ubuntu. There shouldn't be any
problem with other variants, but all the package stuff may be different.


=========== Initial setup ====================================================
On a Pi, you may need to set up more swapfile space; assuming you have enough 
disk space (you will probably need a 16Gb or larger SD card)

sudo nano /etc/dphys-swapfile

and change

CONF_SWAPSIZE=100

to CONF_SWAPSIZE=2000

exit and save the file, then reboot for it to take effect.

If git isn't installed, you need to install it:

sudo apt-get install git


Go to your home directory 

cd

 and check out Minos

git clone git://git.code.sf.net/p/minos/minos Minos2

Then, so that you get the latest release rather than the "bleeding edge" source code

cd Minos2
git checkout Mqt_Release_2.8.x.x

# tools.sh is a script that installs all the pre-requisites that may not already be installed.
# it includes those required for Hamlib as well.
# it also will remove any pre-installed hamlib

sudo ./tools.sh

===================== Building Hamlib 4 ========================================
The current Minos (2.8.0.0) uses hamlib 4.7.0

Look at https://github.com/Hamlib/Hamlib for all the up to date hamlib information,
including their build instructions, from which the following is derived.

This means that you have to download and build it yourself; here is one recipe:

Make sure you have downloaded Minos, 

cd ~

to be sure you are in your home directory,

and run tools.sh (as above)

cd Minos2
sudo ./tools.sh
cd ~

Then

git clone https://github.com/Hamlib/Hamlib.git

cd Hamlib

# get the hamlib 4.7 release branch

git checkout Hamlib-4.7

# and run the build

./bootstrap
./configure
make
sudo make install

The first time that you build and install hamlib, an extra stage is required
so that the built libraries can be found:

sudo ldconfig

===================== Building Minos =========================================== 
Then you can start building Minos. 

cd ~/Minos2/mqt/Installer
./buildInstall.sh


which will update to the latest version of Minos, build it, and put a 
runnable system into ~/minos-runtime. This directory is removed and 
then rebuilt

It will then offer to copy the binaries and then config into the "~/runtime" 
directory which will be created if it doesn't exist.

The config shouldn't overwrite anything that has been changed by the user!
                                                                          
To run it, from the command line type

~/runtime/Minos.sh &

There is a skeleton for a .desktop file in ~/Minos2/mqt/Installer/MqtLogger.desktop
but that is up to you - different systems have different ways of creating desktop
shortcuts. 

To update and build again, 

cd ~/Minos2/mqt/Installer
./buildInstall.sh
