Building under Linux
====================

Currently, these instructions work under Ubuntu, and also on the Raspberry Pi
where the default oS is similar enough to Ubuntu. There shouldn't be any
problem with other variants, but all the package stuff may be different.


If git isn't installed, you need to install it:

sudo apt-get install git


Go to your home directory 

cd

 and check out Minos

git clone git://git.code.sf.net/p/minos/minos Minos2

Then, so that you get the latest release rather than the "bleeding edge" source code

git checkout mqt_Release_2.4

================================================================================
The current Minos (2.4, and the various preceeding beta releases) uses hamlib 4,
which is not yet available in the various Linux repositories - at the time of 
writing, it isn't even released, but is at Release Candidate status.

Look at https://github.com/Hamlib/Hamlib for all the up to date hamlib information,
including their build instructions, from which the following is derived.

This means that you have to download and build it yourself; here is one recipe:

If you have previously been using the system installed hamlib, e.g. for previous
Minos builds

sudo apt remove libhamlib2

Then...

git clone https://github.com/Hamlib/Hamlib.git

cd Hamlib

# get the hamlib 4 release branch

git checkout Hamlib-4.0

# These two installs may not be needed, they may be installed already
sudo apt-get install cmake
sudo apt-get install build-essential

# These two may be installed, but I have normally needed them
sudo apt-get  install libtool
sudo apt-get install automake

./bootstrap
./config
make
sudo make install


Once hamlib 4 is fully released, or another release candidate comes out, you will
need to execute

cd ~/Hamlib
git pull
./config
make
sudo make install

================================================================================ 
Then you can start building Minos. tools.sh is a script that installs all the 
pre-requisites that may not already be installed.

cd Minos2
sudo ./tools.sh 

cd ~/Minos2/mqt/Installer
cd mqt/Installer
./buildInstall.sh


which will update to the latest version of Minos, build it, and put a runnable system into ~/minos-runtime.

To run it, from the command line type

~/minos-runtime/Minos.sh &

To update and bulid again, 

cd ~/Minos2/mqt/Installer
./buildInstall.sh
